# AI Content Marketing Using UGC Ads

## Bean & Bloom Café ☕

### 1. Project Overview

This project focuses on using AI-powered prompt engineering
to create engaging advertising content for a fictional
coffee shop called Bean & Bloom Café.

The project demonstrates how AI can generate UGC-style
advertisements, social media captions, and promotional
content for a local business.

### 2. Business Information

- Business Name: Bean & Bloom Café
- Business Type: Coffee Shop
- Tagline: Where Every Sip Feels Like Home.
- Featured Product: Cold Coffee
- Target Audience: Students and young professionals
- Brand Personality: Warm, cozy, friendly, and modern

### 3. Tools Used

- ChatGPT
- Prompt Engineering
- GitHub

### 4. Project Objectives

- Generate engaging UGC-style advertising scripts.
- Create attention-grabbing advertising hooks.
- Develop problem-solution-CTA advertisements.
- Create social media captions for different platforms.
- Maintain a consistent brand voice.

### 5. Key Deliverables

1. UGC Advertisement Script
2. Advertising Hooks
3. Problem-Solution-CTA Advertisement
4. Social Media Captions
5. Advertising Variations
6. Prompt Engineering Documentation
7. Prompt Testing and Evaluation

### 7. Prompt Engineering Approach

The prompts use the following elements:

- Role: Advertising copywriter or marketing specialist.
- Context: Coffee shop business information.
- Audience: Students and young professionals.
- Objective: Generate advertising content.
- Tone: Friendly, casual, and relatable.
- Output Format: Scripts, hooks, and captions.

### 8. Expected Outcome

The project demonstrates how structured prompts can
generate relevant advertising content for a local
business across different social media platforms.

### 9. Conclusion

This project demonstrates the use of prompt engineering
for AI-powered content marketing and advertising.

It highlights how structured prompts can help create
consistent promotional content for a local business.
